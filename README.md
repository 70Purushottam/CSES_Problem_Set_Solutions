# CSES Problem Set Solutions

Solutions to problems from the [CSES Problem Set](https://cses.fi/problemset/), organized by topic.

## 📂 Structure

| Folder | Topic |
|---|---|
| `Introductory Problems` | Basic problem-solving and implementation |
| `Sorting and Searching` | Sorting algorithms, binary search, greedy techniques |
| `Sliding Window Problems` | Two-pointer and sliding window techniques |
| `Dynamic Programming` | Classic and advanced DP problems |
| `Range Queries` | Segment trees, Fenwick (BIT) trees, sparse tables |
| `Graph Algorithms` | Graph traversal, shortest paths, connectivity, and more |

Each folder contains individual solution files corresponding to specific CSES problems within that topic.

## 🎯 Purpose

This repository serves as a personal archive of solved CSES problems, useful for:
- Practicing and revising core data structures & algorithms concepts
- Reference implementations for common problem patterns
- Tracking progress through the CSES Problem Set

## 🚀 Usage

Browse the folder matching the topic you're interested in, then open the relevant solution file to see the implementation.
